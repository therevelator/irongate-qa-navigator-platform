# QE Navigator pitch deck (source)

Source files of the pitch deck (11 slides, 16:9): `deck.json` (order, sections, fonts), `deck.css`
(shared styles) and one HTML file per slide in `slides/`, with speaker notes in each slide's `<aside>`.

The presentable version, which can be downloaded as PowerPoint or PDF, is the private Slides
artifact: https://claude.ai/artifact/54HY2m5Q4rStxRoifqiowq

Proposed list prices (business model slide, excluding VAT): platform €249 per team per month billed
yearly, from 3 teams; guided onboarding €4,500 one-off; quality programme €7,500 per quarter; pilot
€6,000 for 90 days, up to 5 teams, onboarding included, credited against year one. The basis (market
per-contributor prices and an assumed €900 consultant day rate) is in the speaker notes.

Placeholders to fill before presenting: presenter, date and audience (cover); client, start date and
contact (the ask).
Role names follow the product: Managers, Team leads and Software engineers (quality is a shared
responsibility, not a separate QA function).
Competitive claims come from `docs/COMPETITIVE_ANALYSIS.md` (sources checked 18 Nov 2026).
