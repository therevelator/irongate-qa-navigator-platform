# Reports

Point-in-time reports produced while reviewing the platform. They describe the code as it was when
written; findings have since been fixed (see the release plan and git history), so read them as
background, not as the current state.

- `accuracy-audit-*.md`: four read-only audits of the numbers shown in the app (developer metrics,
  quality and delivery pages, executive overview and team scores, business-impact statistics) that
  led to the "no invented numbers" accuracy fixes.
- `consistency-report.md`: the scan for logical inconsistencies across the project.
