# Archive

Historical documents. They describe the product, the code or the plans as they were when written
(status reports, fix logs, old setup guides for MySQL / Aiven / AWS, early roadmaps, marketing drafts,
old test scenario lists). They are kept for the record. Do not use them as a reference: many
endpoints, file paths, roles and numbers in them are wrong today.

The current documentation is listed in [docs/DOCUMENTATION_INDEX.md](../DOCUMENTATION_INDEX.md).

| Folder | Came from |
|---|---|
| `root/` | Markdown files that were in the repository root |
| `github/` | Notes that were in `.github/` |
| `tests/` | Scenario lists and notes that were in `tests/` (the current test docs are in `docs/testing/`) |
| `authentication/`, `business/`, `features/`, `technical/`, `release-r2/` | The same folders under `docs/` |
| (top level) | Files that were directly in `docs/` |
